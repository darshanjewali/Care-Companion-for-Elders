# UI/UX Design Specification (Elder-First)

## Accessibility Standards
- Minimum font size: 18px, default 20px for critical actions.
- Color contrast ratio target: 7:1 for key text/actions.
- Touch targets minimum 52px.
- Voice command fallback on all primary screens.

## Screen Inventory
1. Splash Screen
2. OTP Login/Register
3. Elder Dashboard (one-click cards)
4. Medicine Reminder
5. Appointment Scheduler
6. Health Tracker + Graphs
7. Emergency SOS (large red button)
8. Voice Assistant
9. Profile + Caregiver Linking
10. Reports Dashboard
11. Settings (language, accessibility, dark mode)

## Language Support
- English (`en`)
- Hindi (`hi`)
- Kannada (`kn`)

## UX Interaction Rules
- No deep nested menus for elder personas.
- Critical actions always available from bottom nav.
- Confirmation + undo for high-risk actions (SOS cancel window).
